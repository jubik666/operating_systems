## Условие задания

**Группа вариантов 2.** Родительский процесс создаёт один дочерний процесс
(разные программы). Первой строкой пользователь вводит в консоль родительского
процесса имя файла, которое будет использовано для открытия файла с таким
именем на чтение. Стандартный поток ввода дочернего процесса переопределяется
открытым файлом. Дочерний процесс читает команды из стандартного потока ввода.
Стандартный поток вывода дочернего процесса перенаправляется в `pipe1`.
Родительский процесс читает из `pipe1` и прочитанное выводит в свой стандартный
поток вывода.

**Вариант 10.** В файле записаны команды вида `число<endline>`. Дочерний
процесс производит проверку этого числа на простоту:
- если число **составное** — дочерний процесс пишет это число в стандартный
  поток вывода;
- если число **отрицательное или простое** — дочерний и родительский процессы
  завершаются.

## Структура проекта

```
common.h    — объявления: line_reader_t, read_line, line_reader_init, die_errno
common.c    — реализация общих функций (используются и parent, и child)
parent.c    — родительский процесс: open, pipe, fork, dup2, execv, waitpid
child.c     — дочерний процесс: is_prime, parse_long, write_long_line
Makefile    — сборка
README.md   — этот файл

test1.txt   — все числа составные
test2.txt   — остановка на простом числе (17)
test3.txt   — остановка на отрицательном числе (-3)
test4.txt   — последняя строка без завершающего \n
test5.txt   — граничный случай: числа 0 и 1
```

## Сборка

```bash
make
```

Собирает два исполняемых файла: `parent` и `child` (в корне проекта).

```bash
make clean
```

Удаляет бинарники и объектные файлы (`*.o`).

## Запуск

`parent` и `child` должны находиться в одной директории — `parent` запускает
`child` через `execv("./child", ...)`, то есть ищет его в текущей рабочей
директории.

```bash
./parent
```

Программа попросит ввести имя файла с числами:

```
test1.txt
```

Либо без интерактивного ввода, через пайп:

```bash
echo "test1.txt" | ./parent
```
