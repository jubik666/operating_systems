## Условие задания

Переделать лабораторную работу №1 так, чтобы родительский и дочерний процессы
обменивались данными не через `pipe`, а через **именованную shared memory**
(`shm_open` + `mmap`). Блокирующего чтения из канала больше нет, поэтому
чтение и запись синхронизируются **семафорами**.

**Вариант 10 (как в лабе 1).** В файле записаны числа по одному в строке.
Дочерний процесс проверяет число на простоту:
- если число **составное** — передаёт его родителю, родитель печатает его в stdout;
- если число **отрицательное или простое** — дочерний и родительский процессы завершаются.

Числа 0 и 1 — не простые и не составные: child передаёт родителю сообщение,
parent печатает `ERROR: N is neither prime nor composite`, обработка продолжается.

Требования: имена shared memory и семафоров **не константные** (содержат PID
родителя); только `shm_open` (без `shmget`/`shmat`, без файла в `/tmp`);
системные ошибки обрабатываются.

## Как это работает

- parent создаёт shared memory `/lab3_<pid>_shm` (размер — один `shared_t`),
  отображает её `mmap(MAP_SHARED)` и создаёт два именованных семафора:
  `/lab3_<pid>_empty` (начальное значение 1 — «слот свободен») и
  `/lab3_<pid>_full` (начальное значение 0 — «в слоте есть данные»).
- parent делает `fork`, подставляет открытый файл вместо `stdin` ребёнка
  (`dup2`) и запускает `./child`, передавая ему три имени через `argv`.
- child подключается к объектам по именам и для каждого числа делает
  `sem_wait(empty)` → запись `state`/`value` в слот → `sem_post(full)`.
- parent в цикле: `sem_wait(full)` → копирует `state`/`value` → `sem_post(empty)` → печатает.
- Конца канала (EOF) больше нет, поэтому child в конце **всегда** отправляет `SLOT_END`
  (при EOF файла, простом или отрицательном числе).
- Удаляет объекты (`sem_unlink`, `shm_unlink`) только parent, после `waitpid`.

## Сборка

```bash
make
```

Собирает `parent` и `child`. `make clean` удаляет бинарники и `*.o`.

## Запуск

`parent` и `child` должны лежать в одной директории (`execv("./child", ...)`).

```bash
./parent
```

Ввести имя файла с числами, например `test1.txt`. Или без интерактивного ввода:

```bash
echo "test1.txt" | ./parent
```

## Тесты

| Файл | Вход | Вывод |
|---|---|---|
| `test1.txt` | `4 6 8 9 10` | `4 6 8 9 10` |
| `test2.txt` | `4 6 17 100` | `4 6` (стоп на 17) |
| `test3.txt` | `10 15 -3 20` | `10 15` (стоп на -3) |
| `test4.txt` | `12 9 17` (без `\n`) | `12 9` |
| `test5.txt` | `0 1 4 6` | `ERROR: 0 ...`, `ERROR: 1 ...`, `4`, `6` |
| `test6.txt` | `0 4 1 6 17 9` | `ERROR: 0 ...`, `4`, `ERROR: 1 ...`, `6` (стоп на 17) |

Ошибки: несуществующий файл → `parent: open: No such file or directory`, пустой ввод →
`parent: не введено имя файла` (код возврата 1).
