# Лаба 2 — Вариант 10: метод Гаусса (последовательно + параллельно, pthreads)

Архитектура — Fork & Join: на каждом шаге метода Гаусса потоки создаются заново (`pthread_create`) и дожидаются через `pthread_join`, без отдельного барьера или пула.

## Файлы

- `matrix.h/.c` — генерация диагонально доминирующей матрицы, копирование, проверка невязки.
- `seq_gauss.h/.c` — последовательный метод Гаусса.
- `par_gauss.h/.c` — параллельный метод Гаусса (Fork & Join).
- `main.c` — CLI, замер времени, расчёт speedup/efficiency.
- `Makefile` — сборка.
- `run_experiments.sh` — прогоняет набор потоков для таблицы отчёта.

## Сборка и запуск

```sh
make
./lab2 <n> <max_threads> [seed]
```

`max_threads = 0` — только последовательная версия. Без `seed` — по умолчанию `42`.

Пример:
```sh
./lab2 2000 4
```

Таблица для отчёта:
```sh
chmod +x run_experiments.sh
./run_experiments.sh 2000 10   # 10 - логических ядер на M2 Pro
```

Наиболее эффективное 6 потоков, потому, что процессор m2 pro имеет 10 ядер, из которых 6 производительных и 4 эффективных
